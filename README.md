# 서울시 모기 채집량과 기온의 관계 분석
### 기초 상관분석 및 시차 분석 (2011–2014)

## 1. 프로젝트 소개
서울시 유문등 모기 채집 자료와 기상청 서울 관측소(108)의 일별 기상 자료를 결합하여,
기온과 모기 채집량 사이의 관계를 탐색한 데이터 분석 프로젝트입니다.

이번 프로젝트는 추가 자료를 확보하지 않고 현재 제공된 파일만 사용했습니다.
분석은 **기초 분석**과 **시차 분석**으로 구성했습니다.

## 2. 프로젝트 구성

mosquito-temperature-analysis/

## 3. 데이터 출처
- **모기 채집 자료:** 서울특별시 보건환경연구원, 2008–2023년 유문등 채집 모기개체 수 현황
  - 데이터 페이지: https://data.seoul.go.kr/dataList/OA-22301/F/1/datasetView.do
  - 원본 메타데이터에 기재된 이용허락: 공공누리 제1유형(출처표시)
- **기상 자료:** 기상청 종관기상관측(ASOS) 일자료, 서울 관측소(108)
  - API 안내: https://apihub.kma.go.kr/apiList.do?seqApi=2
  - 분석에 실제 포함된 일자료 파일: 2011–2014년

> 참고: `sources.json`에는 기상자료 수집 기간이 2008–2023년으로 기록되어 있으나,
> 이 저장소의 `data/raw/`에 포함된 기상 원본 파일은 2011–2014년 4개 연도입니다.
> 따라서 실제 분석 기간은 모기 자료와 기상 자료가 겹치는 2011–2014년입니다.
> API 인증키는 저장소에 포함하지 않았습니다.

## 4. 분석 범위 및 방법

### 기초 분석
- 기간: 2011–2014년
- 계절 범위: 4월–11월
- 단위: 월별 관측값 32개
- 모기 채집량: 해당 월의 주별 채집량 합계
- 기온: 해당 월의 일별 평균기온, 일별 최고기온, 일별 최저기온 평균
- 분석: Pearson 상관계수 및 Spearman 순위상관계수

### 시차 분석
- 단위: 주별 관측값 122개
- 모기 채집량: 주별 유문등 채집 개체 수
- 기온: 해당 주와 채집 주 시작일 이전 7일·14일·21일의 평균
- 분석: 기온 지표별 Pearson 및 Spearman 상관관계 비교

### 날짜 매칭 관련 가정
모기 자료에는 `4월 2주`와 같은 주차 표기가 있고, 정확한 채집 시작일·종료일은 제공되지 않았습니다.
시차 분석에서는 주차를 날짜로 환산하기 위해 해당 월의 1주를 1–7일, 2주를 8–14일과 같이
7일 단위로 추정했습니다. 월의 마지막 주 등 실제 채집 주기와 다를 수 있으므로
시차 분석 결과는 **잠정적인 탐색 결과**로 해석해야 합니다.

## 5. 주요 분석 결과

### 기초 분석: 월별 기온과 모기 채집량
| 기온 지표 | Pearson r | p-value |
|---|---:|---:|
| 월평균기온 | 0.549 | 0.0011 |
| 월평균 최고기온 | 0.509 | 0.0029 |
| 월평균 최저기온 | 0.565 | 0.0007 |

세 기온 지표 모두 모기 채집량과 양의 상관관계를 보였습니다.
이 분석에서는 월평균 최저기온의 상관계수가 가장 높게 나타났습니다.

### 시차 분석: 선행 기온과 주별 모기 채집량
| 기온 지표 | 동일 주 | 7일 전 | 14일 전 | 21일 전 |
|---|---:|---:|---:|---:|
| 평균기온 | 0.412 | 0.506 | 0.528 | 0.561 |
| 최고기온 | 0.385 | 0.479 | 0.505 | 0.544 |
| 최저기온 | 0.419 | 0.508 | 0.531 | 0.562 |

선행 기온의 상관계수가 동일 주 기온보다 높게 나타났으며,
21일 전 평균기온 및 최저기온에서 상대적으로 높은 상관계수가 관찰되었습니다.

## 7. 해석 및 한계
- 상관관계는 인과관계를 의미하지 않습니다.
- 모기 자료는 실제 개체군 규모가 아니라 유문등에 포집된 개체 수입니다.
- 포집기 수, 운영 시간, 설치 위치 등 채집 노력의 연도별 일관성은 제공 자료만으로 확인할 수 없습니다.
- 월별 기초 분석은 32개 관측값, 주별 시차 분석은 122개 관측값으로 표본이 제한적입니다.
- 모기 주차의 정확한 날짜가 없어 시차 분석에는 날짜 추정이 포함됩니다.
- 강수량은 원본 기상자료에 결측 코드(-9)가 다수 있어 핵심 분석에서 제외했습니다.
- 따라서 결과는 기온과 모기 채집량의 관계를 살펴본 탐색적 분석으로 해석해야 합니다.

## 8. 분석 결론
제공된 자료의 범위에서 기온과 모기 채집량 사이에는 양의 상관관계가 관찰되었습니다.
특히 주별 분석에서는 채집 주 시작 전 1–3주 기온과의 상관계수가 동일 주 기온보다 높았습니다.
다만 자료의 날짜 매칭 가정과 채집 노력 정보의 부재 등을 고려할 때,
특정 시차가 모기 증가에 미치는 영향을 확정적으로 결론 내릴 수는 없습니다.
